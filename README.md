# ML from Scratch

This repository contains classic machine learning algorithms implemented from scratch using NumPy. Below are the algorithms included and their benchmark results compared to scikit-learn.

## Algorithms

1. **Linear Regression**: Implements both normal equation and gradient descent methods.
2. **Logistic Regression**: Uses gradient descent for optimization.
3. **K-Means Clustering**: An unsupervised learning algorithm for clustering.
4. **Decision Trees**: A simple yet powerful classification technique.
5. **Random Forest**: An ensemble method based on decision trees.
6. **Naive Bayes**: A probabilistic classifier based on Bayes' theorem.
7. **Support Vector Machines**: A linear classifier with margin maximization.
8. **K-Nearest Neighbors**: A simple, instance-based learning method.
9. **Gradient Boosting**: An ensemble method that builds trees sequentially.
10. **Polynomial Features**: Expands features to polynomial terms for better fitting.

## Regularization

This project demonstrates overfitting and underfitting through regularization techniques. You'll find examples in the `linear_regression.py` file and how polynomial features can affect model performance.
